# Tweet Validation Template

## Template

Question for devs:

{{question}}

Context: {{context}}

What would make this actually useful for you?

## Variables

- `question` - The core question to ask
- `context` - Background context about what you're building

## Example

Question for devs:

Would you use an AI router that saves 50% on API costs?

Context: Been building Ultra-Dex for 2 months. 306 tests passing.

What would make this actually useful for you?
