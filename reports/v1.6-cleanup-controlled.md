# V1.6 - Controlled Cleanup Protocol

**Source:** UD_2 + UD_4 Analysis  
**Agent:** Qwen CLI  
**Priority:** P3 (After execution works)  
**Duration:** 30 minutes

---

## OBJECTIVE
Remove fake features and unused code. **Controlled cleanup only.**

---

## CRITICAL RULE (FROM UD_4)

> "You are trying to optimize a system that is not yet alive"

DO NOT:
- Refactor entire system
- Consolidate subsystems
- Delete files aggressively
- Merge architectures

DO:
- Remove ONLY fake features
- Mark unimplemented as TODO
- Update help text accuracy

---

## PART A: IDENTIFY FAKE FEATURES

### Agent: Qwen CLI
### Duration: 10 minutes

### Prompt
```
TASK: Find features advertised but not implemented

SEARCH FOR:
grep -r "SEARCH_CODE" apps/cli/ --include="*.js"
grep -r "\-\-stream" apps/cli/ --include="*.js"
grep -r "\-\-cache" apps/cli/ --include="*.js"

FOR EACH FOUND:
1. Check if actually implemented
2. If NOT implemented → mark as fake

OUTPUT FORMAT (create reports/fake-features.md):
```markdown
# Fake Feature Audit

## Definitely Fake ❌
| Feature | Location | Evidence |
|---------|----------|----------|
| SEARCH_CODE | ... | No implementation found |

## Partially Implemented ⚠️
| Feature | Location | Status |
|---------|----------|--------|

## Actually Working ✅
| Feature | Location | Verified |
|---------|----------|----------|
```
```

---

## PART B: MARK OR REMOVE FAKE FEATURES

### Agent: Qwen CLI
### Duration: 15 minutes

### Prompt
```
TASK: Handle fake features in code

FOR EACH FAKE FEATURE:

OPTION 1 - Mark as TODO:
```javascript
// TODO: SEARCH_CODE not implemented - planned for v2.0
case 'SEARCH_CODE':
  throw new Error('SEARCH_CODE is not yet implemented');
```

OPTION 2 - Remove from help (if not planned):
Remove the option from command definition.

OPTION 3 - Add [EXPERIMENTAL] marker:
```javascript
.option('--stream', '[EXPERIMENTAL] Enable streaming (not fully implemented)')
```

RULES:
- Do NOT delete implementation code (might be partial)
- Add clear markers
- Update help text to match reality
```

---

## PART C: CONTEXT ENFORCEMENT

### Agent: Qwen CLI
### Duration: 5 minutes

### From UD_2:
> "You load IMPLEMENTATION-PLAN.md, state.json but they are NOT used later"

### Prompt
```
TASK: Verify context is actually used

CHECK:
1. Is IMPLEMENTATION-PLAN.md loaded?
2. Is it injected into prompts?
3. Is state.json used?

IF NOT USED:
- Either remove the load
- OR add actual usage
- OR add TODO comment

RULE:
If loaded → must be used
If not used → remove load (dead code)
```
