## PART A: CONSOLE LINT SCRIPT

### Agent: Qwen CLI
### Duration: 10 minutes

### Prompt
```
TASK: Create lint script to detect console.* in critical files

CREATE FILE: scripts/lint-no-console.sh

CONTENT:
```bash
#!/bin/bash
#
# Ultra-Dex Console Lint
# Fails if console.* found in execution-critical files
#

set -e

echo "🔍 Checking for console.* in critical files..."

FILES=(
  "apps/cli/lib/commands/run.js"
  "apps/cli/lib/commands/commit.js"
  "apps/cli/lib/commands/learn.js"
  "apps/cli/lib/autonomous/agent.js"
  "apps/cli/lib/autonomous/execution-controller.js"
  "apps/cli/lib/providers/nvidia.js"
)

FOUND=0
CLEAN=0

for file in "${FILES[@]}"; do
  if [ -f "$file" ]; then
    # Count console.* calls (excluding comments)
    COUNT=$(grep -v "^\s*//" "$file" | grep -c "console\." 2>/dev/null || echo "0")
    
    if [ "$COUNT" -gt 0 ]; then
      echo "❌ $file: $COUNT console.* calls found"
      # Show the actual lines
      grep -n "console\." "$file" | head -5
      FOUND=$((FOUND + COUNT))
    else
      echo "✅ $file: clean"
      CLEAN=$((CLEAN + 1))
    fi
  else
    echo "⚠️  $file: not found (skipping)"
  fi
done

echo ""
echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"

if [ "$FOUND" -gt 0 ]; then
  echo "❌ FAILED: $FOUND console.* calls found"
  echo ""
  echo "Fix by replacing:"
  echo "  console.log → logger.info"
  echo "  console.error → logger.error"
  echo "  console.warn → logger.warn"
  echo ""
  exit 1
fi

echo "✅ PASSED: All $CLEAN files use logger"
exit 0
```

MAKE EXECUTABLE:
chmod +x scripts/lint-no-console.sh
```

## PART C: PRE-COMMIT HOOK (OPTIONAL)

### Agent: Qwen CLI
### Duration: 3 minutes

### Prompt
```
TASK: Add pre-commit hook to prevent bad commits

IF .husky folder exists:
FILE: .husky/pre-commit

ADD:
```bash
#!/bin/sh
. "$(dirname "$0")/_/husky.sh"

# Check for console.* in critical files
npm run lint:console

# If fails, commit is blocked
```

IF no husky:
Create simple git hook:

FILE: .git/hooks/pre-commit
```bash
#!/bin/sh

echo "Running pre-commit checks..."

# Console lint
if [ -f "scripts/lint-no-console.sh" ]; then
  bash scripts/lint-no-console.sh
  if [ $? -ne 0 ]; then
    echo "Pre-commit check failed. Fix issues before committing."
    exit 1
  fi
fi

exit 0
```

chmod +x .git/hooks/pre-commit
```
