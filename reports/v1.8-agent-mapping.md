## TASK ASSIGNMENT FORMAT

When assigning tasks to agents, use this format:

```markdown
═══════════════════════════════════════════
AGENT: [Agent Name]
═══════════════════════════════════════════

TASK:
[Clear single objective]

FILES:
- [exact file path 1]
- [exact file path 2]

SUCCESS CONDITION:
[Testable output or command]

DO NOT:
- [restriction 1]
- [restriction 2]

VALIDATION:
[command to verify completion]
═══════════════════════════════════════════
```

## PRIORITY ENFORCEMENT RULE

**Before assigning any task, check:**

```
IF task ∉ {P0, P1} AND P0 is not complete:
  → REJECT TASK

IF task affects:
  - UI
  - DX
  - Templates
  - Documentation
  
AND ultra-dex run does NOT work:
  → REJECT TASK
```

## AGENT DRIFT DETECTION

### Signs of Drift
```
❌ Agent working on UI/banner/theme
❌ Agent writing documentation
❌ Agent creating dashboards
❌ Agent optimizing performance
❌ Agent refactoring architecture
❌ Agent adding templates
```

### Correction Action
```
STOP IMMEDIATELY

REDIRECT TO:
1. Is ultra-dex run working? → If NO, fix that first
2. Is provider connected? → If NO, fix that first
3. Is execution bounded? → If NO, fix that first
```

## AGENT PROMPTING TIPS

### For Codex
```
- Be specific about files
- Give exact code snippets
- Set clear boundaries
- Use --sandbox workspace-write
```

### For Gemini
```
- Structure as JSON when possible
- Give step-by-step instructions
- Use --approval-mode auto_edit
```

### For Qwen
```
- Give batch operations
- Simple, repetitive tasks
- Include validation commands
- Use --approval-mode auto-edit
```

### For DeepSeek
```
- Ask for analysis, not implementation
- Request structured output
- Use for planning/auditing
```
