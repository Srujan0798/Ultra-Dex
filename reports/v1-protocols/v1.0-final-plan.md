## Executive Summary

Ultra-Dex is currently a **powerful but uncoordinated execution engine**. Before introducing V2.0 agents, the system must achieve:

1. **Deterministic Execution** - Every run produces traceable, reproducible output
2. **Unified Logging** - Single spine for all observability
3. **Provider Integration** - NVIDIA multi-key connected to execution flow
4. **Bounded Agent Loop** - No unbounded recursion
5. **First-Class Output** - Results always visible, not flag-dependent

### PHASE 6: Bound Agent Loop
**Task:** Replace unbounded recursion with controlled steps.

**Implementation:**
```javascript
const MAX_STEPS = 10;
let step = 0;

while (step < MAX_STEPS && !isComplete) {
  step++;
  // execute step
  trace.steps.push({ step, ... });
}

if (step >= MAX_STEPS) {
  logger.warn("Max steps reached", { run_id, step });
}
```

### PHASE 9: Connect NVIDIA Provider
**Task:** Wire NVIDIA multi-key to execution engine.

**Step 1 - Create Provider Adapter:**
```javascript
// apps/cli/lib/providers/nvidia.js
import { initNVIDIAKeys, createRotatingClient } from '../../../src/services/ai-providers/nemotron.js';

export class NVIDIAProvider {
  constructor() {
    initNVIDIAKeys();
  }

  async generate(messages, options = {}) {
    const model = options.model || "nvidia/nemotron-3-super-120b-a12b";
    const { client } = createRotatingClient(model);
    
    const response = await client.chat.completions.create({
      model,
      messages
    });
    
    return response.choices[0].message.content;
  }
}
```

**Step 2 - Register in Provider Factory:**
```javascript
// apps/cli/lib/providers/index.js
import { NVIDIAProvider } from './nvidia.js';

export function createProvider(name) {
  switch (name) {
    case 'nvidia':
    case 'nemotron':
      return new NVIDIAProvider();
    // ... existing providers
  }
}
```

**Step 3 - Use in run.js:**
```javascript
const provider = createProvider(config.provider || "nvidia");
```
