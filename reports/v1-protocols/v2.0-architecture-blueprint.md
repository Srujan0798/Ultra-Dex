# V2 Integration Contract — run.js ↔ Core

> Non-breaking integration plan. Current runAgentLoop continues working.
> V2 path is feature-flagged, default OFF.

## Contract Overview

```
Current Flow (unchanged):
  run command → createProvider → runAgentLoop → output

V2 Flow (feature-flagged, default OFF):
  run command → CapabilityRouter.route(task) → Scheduler → ExecutionEngine → output
```

## Step-by-Step Mapping

### Step 1: Agent Selection
```
Current:  agentName passed directly via CLI: `ultra-dex run planner -t "hello"`
V2:       CapabilityRouter.route(task) → { agent, confidence, reason }
Contract: If confidence < 0.4, fall back to CLI-specified agentName.
```

### Step 2: Task Preparation
```
Current:  buildPromptContextSection() + createInteractionSummary()
V2:       Scheduler.addTask({ agent, task, dependencies: [], priority })
Contract: V2 tasks use same prompt context builder as current flow.
```

### Step 3: Execution
```
Current:  runAgentLoop(agentName, task, providerFactory, context, 0, maxSteps)
V2:       ExecutionEngine.execute(agentName, task, { runId })
Contract: Engine uses same provider factory. Same governance checks. Same artifact writing.
```

### Step 4: Output
```
Current:  finalOutput → persistAndPrintRunArtifacts()
V2:       ExecutionEngine result → same persistAndPrintRunArtifacts()
Contract: Identical artifact format. Same trace.jsonl, summary.json, result.txt.
```

## Invariants (MUST NOT CHANGE)

1. **Provider contract**: Same `createProvider(providerId, options)` call
2. **Governance**: Same `authorizeOperation()` checks
3. **Artifacts**: Same `.ultra-dex/runs/$runId/{trace.jsonl, summary.json, result.txt}`
4. **Memory**: Same `ultraMemory` update flow
5. **Analytics**: Same `analytics.agent_performance` and `analytics.token_usage` events
6. **Error recovery**: Same `errorRecovery` integration

## Feature Flag

```javascript
// In run.js, gated by env var (default: false)
const USE_V2_ROUTING = process.env.ULTRA_DEX_V2_ROUTING === '1';

if (USE_V2_ROUTING) {
  // V2 path: router → scheduler → engine
} else {
  // Current path: runAgentLoop (unchanged)
}
```

## Activation Sequence

1. **Phase 1** (current sprint): Core files created, entry-only init in run.js ✅
2. **Phase 2** (next sprint): Feature flag + V2 routing path (default OFF)
3. **Phase 3**: Internal testing with `ULTRA_DEX_V2_ROUTING=1`
4. **Phase 4**: Default ON after validation

## Risk Mitigation

- V2 path is completely isolated behind feature flag
- If V2 fails, falls back to current runAgentLoop
- No changes to existing runAgentLoop logic
- Same error handling, same output format
