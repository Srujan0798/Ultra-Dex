# Ultra-Dex Project Context

## Project Overview
**Name:** Ultra-Dex
**Started:** 2026-01-28
**Status:** Active Development

## Quick Summary
Ultra-Dex is an AI-powered SaaS implementation CLI that orchestrates specialized agents to plan, build, and review code.

## Key Decisions
- **Language:** Node.js (CLI), TypeScript (Extension)
- **Architecture:** Modular CLI with specialized agents
- **AI Integration:** Multi-provider (Claude, OpenAI, Gemini)
- **State Management:** Local file-based (CONTEXT.md, IMPLEMENTATION-PLAN.md)

## Current Focus
Enhancing Swarm mode and finalizing v3.0 features.
