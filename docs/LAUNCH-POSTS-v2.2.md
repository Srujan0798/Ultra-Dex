## GitHub Release Notes

```markdown
## 🚀 Ultra-Dex v2.2.0 - AI-Powered CLI

**AI Commands are here!** Transform ideas into production-ready SaaS plans.

### New Commands

| Command | Description |
|---------|-------------|
| `generate` | AI-powered 34-section plan generation |
| `build` | AI-assisted dev with 10 specialized agents |
| `review` | Code vs plan alignment checking |
| `align` | Quick alignment score (0-100) |

### Quick Start

```bash
# Install
npm i -g ultra-dex

# Set API key
export ANTHROPIC_API_KEY=your-key

# Generate plan
ultra-dex generate "A booking platform for pet groomers"

# Build with AI
ultra-dex build --agent planner

# Check progress
ultra-dex align
```

### Supported AI Providers
- Claude (Anthropic) - recommended
- OpenAI GPT-4
- Google Gemini
```
