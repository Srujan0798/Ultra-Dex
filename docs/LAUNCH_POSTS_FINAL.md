## Reddit (r/programming, r/webdev)
**Title:** Ultra-Dex v3.2 — Open source AI orchestration framework with 16 agents, swarm mode, and MCP server

**Body:**
Hey everyone! Just released Ultra-Dex v3.2.

**What is it?**
Ultra-Dex is the orchestration layer that sits ABOVE AI coding tools (Claude Code, Cursor, Devin). It provides:
- Persistent context (CONTEXT.md survives sessions)
- 16 specialized agents (planner, backend, frontend, etc.)
- Swarm mode for autonomous pipelines
- MCP server for Claude Desktop integration

**What's new in v3.2?**
- ✨ **Professional Purple Theme:** A modern, clean indigo-to-pink gradient interface.
- 🚀 **Stability:** Improved swarm coordination and state management.
- 🔧 **Enhanced CLI:** 37+ commands for full-lifecycle development.

**Why?**
AI tools have amnesia. Ultra-Dex is their memory. It keeps your project's single source of truth in Git-versioned files so any AI can pick up where the last one left off.

**Quick start:**
