# User Research Plan: Ultra-Dex New Features

**Generated:** 2026-04-11  
**Objective:** Understand user needs for LiteLLM adapter and VS Code extension

## Research Questions

### Primary

1. What providers do users currently use and why?
2. How important is provider flexibility vs. simplicity?
3. What would make VS Code integration valuable?

### Secondary

4. What are pain points with current CLI-only workflow?
5. How do users debug when things go wrong?
6. What integrations would save time?

## Interview Guide

### Intro (5 min)

- Thank you for participating
- About Ultra-Dex, your role

### Provider Questions (15 min)

- Which AI providers do you use?
- How do you decide which provider?
- What's your biggest frustration with providers?

### VS Code Questions (15 min)

- How do you work with code today?
- What IDE do you use?
- What would you want from VS Code integration?

### Wrap-up (10 min)

- Any other thoughts?
- Would you be available for follow-up?
