## 2. Schema Definitions

### 2.1 Test Results Schema

```sql
CREATE TABLE test_results (
  id UUID PRIMARY KEY,
  test_name VARCHAR(255) NOT NULL,
  module VARCHAR(50) NOT NULL,
  category VARCHAR(20) NOT NULL, -- unit, integration, cli, e2e
  status VARCHAR(20) NOT NULL, -- passed, failed, skipped
  duration_ms INTEGER NOT NULL,
  assertions_count INTEGER,
  coverage_pct DECIMAL(5,2),
  executed_at TIMESTAMP DEFAULT NOW(),
  environment VARCHAR(50)
);
```

**Common Queries:**

```sql
-- Latest test pass rate by module
SELECT module, COUNT(*) as total,
       SUM(CASE WHEN status = 'passed' THEN 1 ELSE 0 END) as passed,
       ROUND(SUM(CASE WHEN status = 'passed' THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as pass_rate
FROM test_results
WHERE executed_at > NOW() - INTERVAL '7 days'
GROUP BY module
ORDER BY pass_rate ASC;

-- Test duration trends
SELECT DATE(executed_at) as date, AVG(duration_ms) as avg_duration
FROM test_results
GROUP BY DATE(executed_at)
ORDER BY date;
```

### 2.2 Audit Log Schema

```sql
CREATE TABLE audit_logs (
  id UUID PRIMARY KEY,
  user_id VARCHAR(100),
  action VARCHAR(100) NOT NULL,
  resource_type VARCHAR(50),
  resource_id VARCHAR(100),
  status VARCHAR(20), -- allowed, denied
  metadata JSONB,
  created_at TIMESTAMP DEFAULT NOW(),
  ip_address VARCHAR(45)
);
```

**Common Queries:**

```sql
-- Policy violations by user
SELECT user_id, COUNT(*) as violations
FROM audit_logs
WHERE status = 'denied'
  AND created_at > NOW() - INTERVAL '30 days'
GROUP BY user_id
ORDER BY violations DESC;

-- Recent governance actions
SELECT action, resource_type, COUNT(*)
FROM audit_logs
WHERE created_at > NOW() - INTERVAL '24 hours'
GROUP BY action, resource_type;
```

### 2.3 Memory Store Schema

```sql
CREATE TABLE memory_entries (
  id UUID PRIMARY KEY,
  session_id VARCHAR(100),
  tier VARCHAR(20) NOT NULL, -- instant, session, persistent
  key VARCHAR(255) NOT NULL,
  value JSONB,
  access_count INTEGER DEFAULT 0,
  last_accessed TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  expires_at TIMESTAMP
);
```

**Common Queries:**

```sql
-- Memory usage by tier
SELECT tier, COUNT(*) as entries,
       SUM(OCTET_LENGTH(value::text)) as size_bytes
FROM memory_entries
GROUP BY tier;

-- Most accessed entries
SELECT key, access_count, last_accessed
FROM memory_entries
ORDER BY access_count DESC
LIMIT 20;
```

## 4. Common Query Patterns

### 4.1 Performance Analysis

```sql
-- Identify slow tests
SELECT test_name, module, duration_ms
FROM test_results
WHERE duration_ms > 1000
  AND executed_at > NOW() - INTERVAL '7 days'
ORDER BY duration_ms DESC
LIMIT 10;

-- Provider latency breakdown
SELECT provider, AVG(latency_ms) as avg,
       MAX(latency_ms) as max,
       COUNT(*) as calls
FROM provider_calls
WHERE created_at > NOW() - INTERVAL '24 hours'
GROUP BY provider;
```

### 4.2 Security Analysis

```sql
-- Failed authentication attempts
SELECT user_id, COUNT(*) as attempts, MAX(created_at) as last_attempt
FROM audit_logs
WHERE action LIKE '%auth%' AND status = 'denied'
GROUP BY user_id
HAVING COUNT(*) > 5;

-- Sensitive data access patterns
SELECT user_id, resource_type, COUNT(*) as accesses
FROM audit_logs
WHERE resource_type IN ('memory', 'credentials')
  AND created_at > NOW() - INTERVAL '7 days'
GROUP BY user_id, resource_type;
```

## 6. Dialect-Specific Notes

### PostgreSQL (Production)

- Use `jsonb` for JSON storage
- Enable `pg_trgm` for fuzzy text search
- Use `EXPLAIN ANALYZE` for query optimization

### SQLite (Local Development)

- Use `JSON1` extension for JSON
- No full-text search by default
- Suitable for datasets <100k rows
