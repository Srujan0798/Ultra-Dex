# Ultra-Dex Quick Start

> Definition for Grade A Alignment

## idea

A unified AI orchestration layer that automates the "Verify" loop in software development.

## problem

Friction in AI development due to manual verification, context loss between tools, and lack of autonomous self-healing.

## mvp

Core CLI with swarm execution, MCP integration, and project-aware memory sync.

## tech stack

- Node.js (v20+)
- TypeScript
- Commander.js
- Anthropic/OpenAI SDKs

## feature

Self-healing test loops that automatically debug and fix code failures without human intervention.
