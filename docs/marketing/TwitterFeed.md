# Twitter / X Feedback Log

## Common Replies
- "Show the architecture" -> share `docs/architecture/system-overview.md`
- "What commands exist?" -> share `docs/api/cli-reference.md`
- "Is feature X shipped?" -> verify against `docs/FEATURES.md`

## Engagement Actions
- Post short CLI demos (plan -> run -> verify)
- Share one practical workflow per post
- Link one docs page per thread for depth

## Messaging Rules
- Do not claim features that are not in repository.
- Explicitly label roadmap content.
- Prioritize reproducible examples over marketing language.
