# Ultra-Dex AI Prompts

Reusable prompts for consistent agent output.

## Planning Prompt
```
Fill Sections 1-8 of IMPLEMENTATION-PLAN.md.
Use atomic tasks (4-9 hours). Provide acceptance criteria for each task.
```

## Implementation Prompt
```
Implement tasks from Section 16 in order. Use existing code patterns. Add tests where needed.
```

## Review Prompt
```
Review code for quality, security, performance, testing, and documentation gaps.
Provide: Summary, Critical Issues, Suggestions, Status.
```

## Debug Prompt
```
Analyze -> Root Cause -> Fix -> Verify. Include regression risk assessment.
```
