## 🔄 MIGRATION GUIDES

### From v5.x to v6.0

**Breaking Changes:** None  
**Action Required:** None  
**Notes:** All v5.x prompts remain compatible

### From v4.x to v5.x

**Breaking Changes:**

- New CLI command structure
- Updated memory system API
- Changed agent initialization

**Migration Steps:**

1. Update CLI to v5.0.0+
2. Run `ultra-dex migrate v4-to-v5`
3. Update agent configurations
4. Verify with `ultra-dex verify`
