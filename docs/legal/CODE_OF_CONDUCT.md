# Code of Conduct

This project is committed to a respectful, safe, and harassment-free community.

## Expected Behavior

- Be respectful in language and feedback.
- Assume good intent, then ask clarifying questions.
- Focus critiques on ideas and code, not people.
- Respect privacy and confidentiality.

## Unacceptable Behavior

- Harassment, hate speech, personal attacks, or threats.
- Publishing private data without consent.
- Spam, doxxing, or intimidation.
- Any activity that violates GitHub's policies or applicable law.

## Scope

This applies to repository spaces (issues, pull requests, discussions, code review)
and project-related communication channels.

## Reporting

For conduct concerns, contact maintainers privately. Do not create public issues for
sensitive reports.

## Enforcement

Maintainers may remove content, limit participation, or ban accounts that violate
this code of conduct.
