## 🌌 KEY PILLARS

### 1. 🧠 Neuro-Symbolic Planning (The "Pre-Cogs")

- **Current:** Linear planning via `generate` command.
- **V5 Goal:** Recursive, self-correcting planning loops that simulate 100 variations of a feature implementation before writing a single line of code.
- **Tech:** Monte Carlo Tree Search (MCTS) integrated into the Planner Agent.

### 2. 🗣️ Native Voice & Vision (The "Jarvis" Interface)

- **Current:** Text-based REPL.
- **V5 Goal:** Full duplex voice conversation. "Ultra, look at this design mockup and build the backend."
- **Tech:** OpenAI Realtime API + Multimodal Vision (Claude 4.5 Vision).

### 3. 🕸️ The Decentralized Swarm (P2P Agents)

- **Current:** Local agent swarm on your machine.
- **V5 Goal:** Allow agents to "hire" other agents from the network. If your local agent gets stuck, it can outsource the task to a specialized agent in the cloud.
- **Tech:** Agent Protocol (AP) + Crypto-payments for compute.

### 4. 🔮 Predictive Debugging

- **Current:** Fixes errors after they happen.
- **V5 Goal:** Predicts runtime errors _while you type_.
- **Tech:** Local LLM (7B param) running constantly in the background, analyzing code flow graph.
