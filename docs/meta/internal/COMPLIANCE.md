# SaaS Compliance Checklist

## GDPR (EU)

- Data processing agreement in place
- Right to access / delete personal data
- Explicit consent for tracking
- Data retention policy documented

## CCPA (California)

- Clear notice of data collection
- Opt-out for sale of personal data
- Right to delete / request data

## SOC 2 (Enterprise)

- Access controls and audit logs
- Secure SDLC documented
- Incident response plan
- Vendor risk management

## Recommended Actions

- Run a privacy impact assessment
- Maintain a data inventory
- Implement breach notification workflow
