## 1. Brand Voice Definition

### Primary Brand Voice

**Professional + Innovative + Developer-Focused**

| Attribute         | Description                         | Tone                             |
| ----------------- | ----------------------------------- | -------------------------------- |
| Professional      | Enterprise-grade, production-ready  | Confident, authoritative         |
| Innovative        | Cutting-edge AI orchestration       | Forward-thinking, ambitious      |
| Developer-focused | Built by developers, for developers | Technical, practical, actionable |

### Brand Voice Guidelines

**Do:**

- Use technical terminology accurately (CLI, API, provider, memory tier)
- Focus on practical benefits (faster, cheaper, more reliable)
- Show code examples and real-world usage
- Emphasize production readiness

**Don't:**

- Use marketing fluff or hyperbole
- Over-simplify technical concepts
- Make unsubstantiated claims
- Use buzzwords without context
