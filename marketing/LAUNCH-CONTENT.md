**Tagline:** The AI meta-layer that turns ideas into production code

**Description:**
Ultra-Dex is the complete toolkit for AI-assisted software development. It coordinates multiple AI agents, maintains persistent context, and ensures production-ready code through a 21-step verification framework.

**Key Features:**
🎯 VS Code sidebar integration - Manage agents from your IDE
⚡ Real-time dashboard - WebSocket-powered live updates
🧠 Session persistence - SQLite database for long-term memory
🎤 Voice-to-Plan - Speak ideas, get implementation plans
💰 Cost estimator - Budget AI usage across providers
📦 60 CLI commands - With smart aliases for speed
📚 34 cursor rules - Production-grade coding standards
✅ 3 example repos - E-commerce, analytics, chat apps

**Why it matters:**
Current AI tools work in isolation. Ultra-Dex is the orchestration layer that coordinates agents, maintains context, tracks alignment, and ensures quality - turning AI from a toy into a production tool.

**Use cases:**
- Solo developers building MVPs
- Teams coordinating AI workflows
- Learning AI-assisted development
- Standardizing code quality

**Tech stack:**
Node.js, TypeScript, SQLite, WebSocket, VS Code API

## 🎯 Hacker News Post

**Title:** Show HN: Ultra-Dex v3.5.0 – AI orchestration with VS Code integration

**Body:**
Hi HN,

We just shipped Ultra-Dex v3.5.0, a complete AI orchestration platform for developers.

**Problem:** Current AI coding tools (Cursor, Copilot, etc.) work in isolation. They don't coordinate, forget context between sessions, and lack verification frameworks.

**Solution:** Ultra-Dex is the "orchestration layer" that:
1. Coordinates multiple AI agents (17 specialized roles)
2. Maintains persistent context (SQLite + embeddings)
3. Tracks plan vs code alignment in real-time
4. Enforces 21-step production-ready verification
5. Integrates into VS Code as a sidebar

**Key features in v3.5.0:**
- VS Code extension with 4 sidebar views
- Real-time WebSocket dashboard
- Voice-to-Plan (speech → implementation)
- Cost estimation across providers
- 60 CLI commands with shell completions
- 34 cursor rules for code standards
- 3 production-ready example repos
- GitHub Actions for CI/CD

**Example workflow:**
```
$ ultra-dex voice "Build a SaaS for team collaboration"
[generates 12-section implementation plan]

$ ultra-dex swarm "Implement authentication"
[planner → backend → security → reviewer agents run in sequence]

$ ultra-dex align
[78% alignment - plan vs code]
```

**Technical details:**
- Node.js CLI with TypeScript
- SQLite for session persistence
- Socket.io for real-time updates
- VS Code API for sidebar integration
- MCP (Model Context Protocol) server
- 95/95 tests passing

**Open source:** MIT licensed, contributions welcome.

Would love your feedback! What features would make this more useful for your workflow?

GitHub: https://github.com/Srujan0798/Ultra-Dex
