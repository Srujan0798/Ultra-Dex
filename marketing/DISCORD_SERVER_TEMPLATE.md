**FAQ 4: Self-Hosting**

```
Q: Can I self-host Ultra-Dex?
A: Absolutely! That's the default.

git clone https://github.com/ultra-dex/ultra-dex
cd ultra-dex
npm install
npm run start

Everything runs locally by default.
```

**FAQ 5: Security**

```
Q: Is my data secure?
A: Yes. Ultra-Dex is designed with security-first:
• Local storage by default
• End-to-end encryption available
• SOC 2 certified
• GDPR compliant
• HIPAA BAA available

Your data never leaves your control unless you explicitly enable cloud features.
```

**FAQ 6: Memory Storage**

```
Q: How does memory storage work?
A: Triple-memory architecture:
• SQLite: Structured data
• ChromaDB: Vector embeddings
• Neo4j: Relationship graphs

This provides fast retrieval and rich context preservation.
```

**FAQ 7: Model Switching**

```
Q: How do I switch between AI models?
A: Simple CLI command:

ultra-dex model use gpt-4
ultra-dex model use claude
ultra-dex model use kimi

Context automatically transfers!
```

**FAQ 8: MCP Servers**

```
Q: What are MCP servers?
A: Model Context Protocol servers allow Ultra-Dex to connect to external tools:
• GitHub
• Slack
• Notion
• And 50+ more

List: ultra-dex mcp list
```

# 📋 MODERATION GUIDELINES

## Moderator Commands

### Warnings

```
!warn @user [reason]
```

### Mutes

```
!mute @user [duration] [reason]
Example: !mute @user 1h Spamming
```

### Kicks

```
!kick @user [reason]
```

### Bans

```
!ban @user [reason]
```

## Moderation Workflow

1. **First Offense:** Verbal warning
2. **Second Offense:** Official warning
3. **Third Offense:** Temporary mute (1-24 hours)
4. **Fourth Offense:** Kick
5. **Severe Violations:** Immediate ban

## Escalation Path

- @Moderators → Handle routine issues
- @Support Team → Technical disputes
- @Admins → Serious violations
- @Owner → Final decisions
