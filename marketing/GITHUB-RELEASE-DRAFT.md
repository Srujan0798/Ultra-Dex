## Release Notes

🚀 **Ultra-Dex v3.5.0 is here!** The most complete AI orchestration platform for developers.

### ✨ What's New

**Major Features:**
- 🎯 **VS Code Extension** - Full sidebar integration with 4 views (Agent Explorer, Swarm Status, Context Preview, Quick Actions)
- ⚡ **Real-Time WebSocket Dashboard** - Instant updates, no polling
- 🧠 **Session Persistence** - SQLite database for long-term memory

**New Commands:**
- `ultra-dex voice` - Speech-to-plan with Whisper
- `ultra-dex estimate` - Cost prediction for AI usage
- `ultra-dex setup` - Interactive configuration wizard
- `ultra-dex history` - Command history and replay
- `ultra-dex batch` - Execute multiple commands
- `ultra-dex check --p0-only` - Critical section validation
- `ultra-dex scaffold --from-plan` - Structure generation

**Integrations:**
- GitHub Actions (verify, align, fix)
- Linear & GitHub Issues sync
- Slack/Discord webhooks
- 34 cursor rules (i18n, analytics, SEO added)

**Developer Experience:**
- 10 command aliases (s, d, v, b, g, i, st, h, m)
- Shell completions (bash + zsh)
- Smart error handling with suggestions
- Enhanced progress bars
