# Marketing & User Validation

This folder contains everything needed to validate Ultra-Dex with real users.

## Files

| File                       | Purpose                                |
| -------------------------- | -------------------------------------- |
| `reddit-posts.md`          | Posts to get feedback from communities |
| `user-interview-script.md` | Questions to ask potential users       |
| `landing-page-copy.md`     | Website copy (create after validation) |

## Timeline

**Week 1: Validation**

- Day 1: Post on Reddit
- Day 2-3: Respond to comments, DM interested people
- Day 4-7: Do 5-10 user interviews

**Week 2: Decide**

- Analyze feedback
- Decide: Continue / Pivot / Stop
- Strip to ONE feature if continuing

**Week 3: Ship**

- Build MVP of validated feature
- Get 3 paying users

## Key Metrics

- [ ] Posted on 3 subreddits
- [ ] 10+ responses received
- [ ] 5 user interviews completed
- [ ] 3 people said they'd pay
- [ ] Decision made: Continue/Pivot/Stop

## Remember

**2 months of building is not wasted if you learn from users now.**

The goal this week: **Find out if anyone actually wants this.**

Good luck.
