## 🚀 How to Use (Choose Your Mode)

### Mode 1: Manual Execution (Recommended for V2.0)

You control every window. Full visibility. Best for critical architecture work.

```bash
# See what's next
cat .protocol/state/PROGRESS.md

# Read the dispatch
cat .protocol/state/v20-phase0-dispatches.md

# Copy command, execute, validate
# (See WORKFLOW-MANUAL.md for full walkthrough)
```

**Time:** ~2-4 hours/day  
**Control:** Complete  
**Best for:** Phase 0-2 (foundation is critical)

---

### Mode 2: Automated Execution (Ultra Orchestrator)

System runs windows automatically. You approve gates.

```bash
# Start automation
npm run ultra:start

# Check status anytime
npm run ultra:status

# See progress
cat .protocol/state/PROGRESS.md
```

**Time:** ~15 min/day  
**Control:** High-level (gates)  
**Best for:** Phase 3-12 (implementation)
