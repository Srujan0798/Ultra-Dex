# Demo Project: Task Management App

This is a sample project showing how to use Ultra-Dex agents.

## Quick Start

### Step 1: Generate Plan
```bash
cat ../.agents/planner.md | pbcopy
# Paste with: "Plan a task management app for freelancers"
```

### Step 2: Build Backend
```bash
cat ../.agents/backend.md | pbcopy
# Paste with planner output
```

### Step 3: Build Frontend
```bash
cat ../.agents/frontend.md | pbcopy
```

### Step 4: Review
```bash
cat ../.agents/reviewer.md | pbcopy
```
