# 🤖 AI SaaS - Agent Usage Examples

This guide shows how to use Ultra-Dex agents to build this specific example.

## 1. Initial Planning
```bash
ultra-dex run "Plan the AI SaaS database schema" --agent planner
```

## 2. Backend Implementation
```bash
ultra-dex run "Implement the OpenAI streaming API route in Next.js" --agent backend
```

## 3. Frontend Implementation
```bash
ultra-dex run "Build a responsive chat interface with streaming support" --agent frontend
```

## 4. Security Audit
```bash
ultra-dex run "Audit the auth middleware and environment variables" --agent security
```

## 5. Full Swarm
```bash
ultra-dex swarm "Build the entire user settings page with usage limits"
```
