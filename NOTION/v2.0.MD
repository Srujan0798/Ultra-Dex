## DEXGRAPH — THE CORE IP

DexGraph is NOT a traditional DAG runner.

**Traditional DAG:** Run Script A → Script B

**DexGraph:** Goal → Reason → Delegate → Verify → Adapt → Continue

DexGraph is a **semantic DAG engine for non-deterministic AI systems**.

### DexGraph Internal Modules

**1. Graph Compiler**

- Transforms natural language goal → executable cognitive graph
- Output: nodes, dependencies, policies, verification rules

**2. Cognitive Nodes**
Each node = decision unit (NOT just a task)

```yaml
node:
  id: implement_auth
  role: engineer
  objective: secure login system
  verification: tests_pass
```

**3. State Engine**
Every node lifecycle:

```
CREATED → READY → RUNNING → VERIFYING → SUCCESS
                           ↘ FAILED → RETRY → RUNNING
                           ↘ BLOCKED (Governance)
                           ↘ ROLLBACK
```

**4. Context Propagation Engine**
Automatic inheritance — no re-prompting:

```
Design → Implementation → Testing → Review
```

Context becomes infrastructure.

**5. Governance Kernel**
Hard rules that AI cannot bypass:

```
IF tests_passed != true → block deploy
IF cost > threshold → pause workflow
IF confidence < threshold → require reviewer
```

### DexGraph Workflow DSL

```yaml
version: dexgraph/v1
name: build-saas-backend
description: Generate full backend with auth, billing, and tests

context:
  repo: "my-saas-app"
  language: "typescript"
  framework: "nextjs"

tasks:
  - id: design_schema
    role: architect
    instruction: "Design database schema for user + subscription"
    output: "schema.prisma"

  - id: implement_auth
    role: engineer
    depends_on: [design_schema]
    instruction: "Implement JWT auth using schema"
    context:
      schema: "{{design_schema.output}}"
    verify:
      type: "unit_test"
      command: "npm test auth"

  - id: implement_billing
    role: engineer
    depends_on: [design_schema]
    instruction: "Integrate Stripe billing"
    parallel: true

  - id: write_tests
    role: tester
    depends_on: [implement_auth, implement_billing]
    instruction: "Write integration tests"

  - id: review
    role: reviewer
    depends_on: [write_tests]
    instruction: "Review code quality and security"
    verify:
      type: "llm_check"
      policy: "no-hardcoded-secrets"

on_failure:
  retry: 2
  rollback: true
```

### DexGraph SDK Usage

```tsx
import { DexGraph, Workflow } from '@ultradex/dexgraph';

const workflow = Workflow.fromYAML('./workflow.dex');

const engine = new DexGraph({
  workflow,
  memory: 'redis://localhost:6379',
  governance: {
    maxCost: 10.00,
    maxTime: 3600
  }
});

const result = await engine.run({
  initialContext: { repo: 'my-saas-app' }
});

engine.on('task.completed', (task) => {
  console.log(`✅ ${task.id} completed`);
});

engine.on('workflow.failed', (error) => {
  console.error(`❌ Workflow failed: ${error.message}`);
});
```

| Feature | Airflow/Prefect | DexGraph |
| --- | --- | --- |
| Task Type | Deterministic Scripts | Non-Deterministic AI Agents |
| Verification | Exit Code (0/1) | LLM Validation + Unit Tests |
| Context | Static Variables | Semantic Memory + RAG |
| Failure | Retry or Alert | Rollback + Agent Reflection |
| Roles | None | Enforced Agent Roles |
| Goal | Run Pipeline | Achieve Outcome |
