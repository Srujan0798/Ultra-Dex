# Ultra-Dex VS Code Extension

Local development extension for browsing Ultra-Dex agents, checking alignment, and quick command access.

## Features
- Sidebar Agent Explorer grouped by tier (16 agents)
- Click an agent to copy its system prompt
- Right-click selection to ask an agent about code
- Status bar alignment score (from CONTEXT.md)
- Commands: Generate Plan, Check Alignment, Select Agent, Ask Agent

## Development
```bash
npm install
npm run compile
```

Press `F5` in VS Code to launch the Extension Development Host.

> Note: Local development only. Do not publish.
