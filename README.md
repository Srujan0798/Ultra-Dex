## 🚀 The Kubernetes of AI Coding

We don't compete with Cursor, Devin, or Windsurf. **We orchestrate them.**

Ultra-Dex is an **Active Meta-Layer** that solves "AI Amnesia." It provides the persistent memory, architectural rules, and verification gates that LLMs lack.

### 🧠 The Problem: "Vibe Coding"
AI coding tools are amazing, but they drift. They forget plans. They hallucinate APIs. They create projects that look good but fall apart at scale.

### 🛡️ The Solution: "Autonomous Engineering"
Ultra-Dex enforces a strict **"Glass Box"** philosophy:
1.  **Protocol 21**: Every feature goes through a 21-step verification gate.
2.  **Persistent Memory**: A `CONTEXT.md` brain that never forgets.
3.  **Gamification**: Leaderboards, XP, and Achievements for shipping code.

## 🏁 Getting Started

### 1. Install the Meta-Layer
```bash
npm install -g ultra-dex
```

### 2. Initialize a Project (with Enterprise Guards)
```bash
mkdir new-saas && cd new-saas
ultra-dex init --enterprise
```

### 3. Start a Challenge
```bash
ultra-dex challenge start "Auth in 30m"
```
