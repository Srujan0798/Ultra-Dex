# @ultra-dex/computer-use-agent

GUI automation and system interaction specialist.

## Usage

```bash
ultra-dex run computer-use-agent -t "Open the browser and search for documentation"
```

## Capabilities

- **gui-automation**: Controlling mouse and keyboard in a graphical environment.
- **browser-control**: Navigating and interacting with web applications.
- **system-commands**: Executing shell and terminal operations.
