# Ultra-Dex v3.0 Developer Guide

Welcome to the autonomous future of software engineering. You are now running **Ultra-Dex v3.0**, a 7-tier agentic framework.

## 🚀 Quick Start

### 1. Monitor Your Project
Start the Active Kernel and watch your alignment in real-time.
```bash
# Start the HTTP server & Dashboard
ultra-dex serve --http &

# Start Watch Mode (auto-updates state on file changes)
ultra-dex watch
```

### 2. Run an Autonomous Swarm
Need to build a new feature? Let the agents coordinate.
```bash
# Execute a task through the 7-tier pipeline
ultra-dex swarm "Implement a new analytics dashboard with Chart.js" --parallel
```

### 3. Maintain High Quality
Your commits are now protected by Ultra-Dex verification.
```bash
# Check your alignment score
ultra-dex align

# See what's missing from your plan
ultra-dex diff

# Run full system validation
ultra-dex validate --scan
```

## 🤖 The 7-Tier Agent System

You can invoke specific agents for targeted tasks:

- **Tier 1 (Leadership):** `@planner`, `@cto`, `@research`
- **Tier 2 (Development):** `@backend`, `@frontend`, `@database`
- **Tier 3 (Security):** `@auth`, `@security`
- **Tier 4 (DevOps):** `@devops`
- **Tier 5 (Quality):** `@testing`, `@reviewer`, `@debugger`, `@documentation`
- **Tier 6 (Specialist):** `@performance`, `@refactoring`

## 🔌 IDE Integration

- **Cursor/Claude Desktop:** Run `ultra-dex config --mcp` to generate your MCP settings.
- **VS Code:** Open the Ultra-Dex sidebar to explore agents and run quick actions.
