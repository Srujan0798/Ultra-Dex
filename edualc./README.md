## 🎯 The Vision

**REST-iN-U = 3-Mode Platform + 14 AI Agents + Sanatana Dharma Integration**

### Three Modes
1. **🏠 ESTATE Mode** - Modern property search with AI analysis
2. **🕉️ INDU Mode** - Traditional Vastu/Jyotish matching ⭐ THE MOAT
3. **⛓️ WEB3 Mode** - Blockchain verification & fractional ownership

### 14 AI Agents (Agent Swarm)
- **Core:** Swarm Conductor
- **Discovery:** 3 agents (Scout, Lifestyle, Neighborhood)
- **Valuation:** 2 agents (Oracle, Prophet)
- **Risk:** 3 agents (Sentinel, Legal, RERA)
- **Dharma:** 3 agents (Vastu, Jyotish, Muhurat) ⭐
- **Transaction:** 2 agents (Negotiation, Finance)

## 🛠️ Tech Stack

**Frontend:** Next.js 14 + TypeScript + Tailwind  
**Backend:** Node.js + Express + Prisma  
**Database:** PostgreSQL (Neon)  
**Cache:** Redis (Upstash)  
**AI/ML:** Python Flask + YOLOv8  
**Blockchain:** Polygon L2 + Solidity  
**Hosting:** Vercel (Frontend) + Render (Backend)
