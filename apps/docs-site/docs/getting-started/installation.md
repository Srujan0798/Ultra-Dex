# Installation

## Requirements

- Node.js 18 or higher
- npm, yarn, or pnpm

## Install the SDK

```bash
npm install @ultra-dex/sdk
```

Or with yarn:

```bash
yarn add @ultra-dex/sdk
```

Or with pnpm:

```bash
pnpm add @ultra-dex/sdk
```

## Verify

```javascript
import { UltraDex } from '@ultra-dex/sdk'
console.log(typeof UltraDex) // → function
```
