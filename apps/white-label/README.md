# Ultra-Dex White-Label Solution

Self-hosted, branded deployment with custom agents and private marketplace.

## Features

- Custom branding (logo, colors, typography)
- Self-hosted control plane
- Custom agent packs
- Private marketplace catalogs

## Configure

Edit JSON under `white-label/config/` then deploy with Docker.

## Deploy

```bash
cd white-label/deploy
docker compose up -d
```
