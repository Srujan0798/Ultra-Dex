# SolidStart + Drizzle ORM Template

Performant full-stack SolidStart apps with type-safe database access via Drizzle ORM.

## Features

- SolidStart (v1+)
- Drizzle ORM
- Type-safe SQL
- High performance reactivity

## Setup

1. `npm install`
2. Update `.env` with your PostgreSQL connection string
3. `npm run db:push`
4. `npm run dev`
