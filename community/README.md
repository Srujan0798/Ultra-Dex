# Ultra-Dex Community

Welcome to the Ultra-Dex community! We're excited to have you here as we build the future of AI orchestration together.

## Getting Involved

There are many ways to contribute to the Ultra-Dex community:

- **Answer questions** in our Discord server
- **Submit pull requests** to improve the codebase
- **Write documentation** to help other users
- **Share your projects** built with Ultra-Dex
- **Report bugs** and suggest features
- **Write blog posts** about your experiences

## Communication Channels

- [Discord](https://discord.gg/ultra-dex) - Real-time chat and community discussions
- [GitHub Issues](https://github.com/ultra-dex/ultra-dex/issues) - Bug reports and feature requests
- [Twitter](https://twitter.com/ultra_dex) - News and updates
- [Blog](https://ultra-dex.dev/blog) - In-depth articles and tutorials

## Community Resources

- [Documentation](https://ultra-dex.dev/docs) - Complete documentation

## Recognition

We recognize community contributions through:

- Contributor acknowledgments in releases
- Special badges and roles in our Discord
- Swag for significant contributions
- Invitations to core team meetings
