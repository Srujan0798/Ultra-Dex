## Short Description (max 100 chars)

## Long Description

**Ultra-Dex brings multi-agent AI orchestration directly into VS Code.**

Stop switching between terminals, browser tabs, and AI tools. With Ultra-Dex you run agents, launch swarms, and search persistent memory — without leaving your editor.

---

### What it does

**Run any agent from the command palette**
Pick from 9 specialized agents: `@Planner`, `@CTO`, `@Backend`, `@Frontend`, `@Database`, `@Auth`, `@DevOps`, `@Reviewer`, `@Debugger`. Each is pre-configured with the right model, temperature, and skill set.

**Launch multi-agent swarms**
Give Ultra-Dex a complex objective and it automatically coordinates multiple agents in parallel — planning, building, reviewing, and verifying — all in one shot.

**83 skills, ready to use**
From `/code-review` and `/architecture` to `/sql-queries`, `/debug`, and `/analyze`. Skills are pre-wired with prompt templates, routing rules, and output schemas.

**Routes across 13 AI providers**
OpenAI, Anthropic, Google, Groq, Mistral, DeepSeek, Cohere, Together, Fireworks, Perplexity, NVIDIA, Grok, Llama 4. Ultra-Dex picks the best provider for each task automatically — or you choose.

**Persistent memory**
Every task result is stored and searchable. Ask Ultra-Dex about decisions made last week, code written yesterday, or errors you've seen before.

**Works with `MOCK_AI=true`**
No API key required to get started. Demo mode shows the full flow without any real AI calls.

---

### Commands

| Command | Shortcut | What it does |
|---|---|---|
| Ultra-Dex: Run Agent | `Cmd+Shift+U` | Run a single agent task |
| Ultra-Dex: Run Swarm | `Cmd+Shift+S` | Launch multi-agent swarm |
| Ultra-Dex: Memory Search | `Cmd+Shift+M` | Search persistent memory |
| Ultra-Dex: Configure | — | Open settings |
| Ultra-Dex: Stop Task | — | Cancel running task |

---

### Getting started

1. Install the extension
2. Install the CLI: `npm install -g @ultra-dex/cli`
3. Press `Cmd+Shift+U` — type your task — hit Enter

That's it. No config required to start.
